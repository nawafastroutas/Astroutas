# Solva — سلسلة ٣٠ يوم (ريلز إنستقرام)

٣٠ فيديو بمقاس 1080×1920 مع موسيقى ومؤثرات صوتية، مبنية على هوية Solva
(الألوان، IBM Plex Sans Arabic وSpace Grotesk، والعلامة).
وثلاثة فيديوهات شاملة تجمعها.

## الملفات

| الملف | الوصف |
|---|---|
| `videos/day-01.webm` … `day-30.webm` | فيديو لكل يوم (١٣–١٨ ثانية) |
| `videos/solva-part-1.webm` | شامل ١: الأيام ١–١٠ (التعريف وبناء الثقة) |
| `videos/solva-part-2.webm` | شامل ٢: الأيام ١١–٢٠ (التثقيف والتفاعل) |
| `videos/solva-part-3.webm` | شامل ٣: الأيام ٢١–٣٠ (البيع والختام) |
| `ep01.html` … `ep30.html` | مصدر كل فيديو، تفتحه بالمتصفح وتضغط «تشغيل مع الصوت» للمعاينة |
| `engine.js` / `engine.css` | المحرك المشترك: الحركة، الأيقونات، الشخصيات، الموسيقى والمؤثرات، الخاتمة |

## قبل النشر: محتوى لازم تراجعه

هذي الحلقات فيها بيانات افتراضية، كل وحدة معلّمة بـ `EDIT` داخل الملف:

- **اليوم ٦** (`ep06.html`): متجر العطور «NOOR» مشروع تجريبي (مكتوب عليه CONCEPT). استبدله بمشروع نفذتوه فعلًا.
- **اليوم ٢٣** (`ep23.html`): أسماء الباقات ومزاياها، والأسعار فاضية وتظهر «اطلب السعر».
- **اليوم ٢٥** (`ep25.html`): الأرقام مثال توضيحي (مكتوب عليها EXAMPLE DATA). حط أرقام عميل حقيقي.
- **اليوم ٢٧** (`ep27.html`): إجابات الأسئلة الشائعة، تأكد إنها تطابق خدماتكم.
- **اليوم ٢٨** (`ep28.html`): تفاصيل العرض (خصم ١٥٪) ومدته.

بعد التعديل، أعد تصدير الحلقة (والجزء الشامل اللي فيها).

## التحويل إلى MP4 (مطلوب لإنستقرام)

الفيديوهات WebM. حوّلها بـ ffmpeg على جهازك:

```bash
for f in videos/*.webm; do ffmpeg -i "$f" -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart "${f%.webm}.mp4"; done
```

## إعادة التصدير

يحتاج Node 18+ وPlaywright وffmpeg:

```bash
npm i playwright && npx playwright install chromium
node render.mjs --mp4            # كل الحلقات مباشرة MP4
node render.mjs 6 23 --mp4       # حلقات محددة
node compile.mjs --mp4           # الثلاثة الشاملة
```
