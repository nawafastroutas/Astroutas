# موشن جرافيك — نادي الفلك والفضاء (٢٠ ثانية)

فيديو تعريفي لشعار **نادي الفلك والفضاء — كلية التربية بالرستاق**، بصيغتين:

| الملف | الأبعاد | الاستخدام |
|---|---|---|
| `out/video-16x9.mp4` | 1920×1080 · 60fps · H.264 + AAC | يوتيوب، العرض على الشاشات |
| `out/video-9x16.mp4` | 1080×1920 · 60fps · H.264 + AAC | ريلز، ستوري، حالة واتساب |

لكل صيغة نسخة صامتة (`-silent`) لمن يريد إضافة موسيقاه الخاصة.

---

## الشعار: متجه مُستخرَج من الأصل، لا رسم تقريبي

`logo-paths.js` ليس إعادة رسم بالعين، بل **تتبّع متجهي للشعار الأصلي نفسه**:

1. كل عنصر (العلامة، السطر العربي، السطر الإنجليزي، الخط الفاصل، سطر الكلية)
   يُقصّ من الصورة الأصلية ويُكبّر **×8** بإعادة تشكيل عالية الجودة.
2. تُحسب عتبة الحبر عند تغطية ٥٠٪ لكل عنصر على حدة، فلا تسمن الحروف ولا تنحف.
3. يُتتبّع الشكل إلى منحنيات بيزييه (ImageTracer) بدقّة ‎0.55‎ بكسل عند ×8
   (أي ‎0.07‎ بكسل من الأصل).
4. تدرّج العلامة مُستخرَج بأقل المربّعات: زاوية ‎21.5°‎ و١٢ محطة لون،
   جذر متوسط الخطأ ‎≈6.8‎ من ٢٥٥ — أي مطابقة بصرية تامة.

النتيجة: الشعار حادّ عند أي دقّة (ليس صورة مكبّرة)، ومطابق للأصل حرفًا بحرف
— لا خطوط بديلة ولا أشكال مشابهة. قورن بالأصل بطرح الصورتين، فلم يظهر فرق
يُذكر سوى حوافّ التنعيم.

## الفكرة: من عمق الفضاء إلى الشعار

| الزمن | المشهد |
|---|---|
| 0.0 – 1.2 | فضاء عميق: نجوم تظهر بالتدريج، سدم بألوان الهوية، انجراف بطيء بعمق مجسّم |
| 1.2 – 3.2 | **نرصد** — كوكبة نجمية تُرسم خطوطها نجمًا بعد نجم |
| 3.5 – 5.6 | **نكتشف** — الكلمة وحدها فوق حقل النجوم المنجرف |
| 5.8 – 7.9 | **نحلم** — شهاب يعبر السماء بذيل مضيء |
| 8.3 – 11.8 | مذنّب يقترب، ثم **يرسم بذيله المضيء مسار الشعار** كاملًا |
| 11.8 – 12.2 | الذيل يخبو والعلامة تمتلئ بتدرّج الهوية |
| 12.2 – 13.0 | **انفجار ضوء** يغسل الليل — ينقلب المشهد إلى أبيض الهوية |
| 13.0 – 16.2 | العلامة تستقر، ثم العنوان العربي (من اليمين)، الإنجليزي، الخط، سطر الكلية |
| 16.4 – 17.7 | لمعة ضوء تعبر الشعار |
| 17.7 – 20.0 | ثبات هادئ ثم تلاشٍ — فيتكرّر المقطع بسلاسة |

**الصوت مؤثرات فقط، بلا موسيقى** (`synth.js`): لا نغمات ولا أوتار — كلها ضوضاء
مُرشَّحة وكنسات وضربات، مولَّدة برمجيًا ومتزامنة مع المشهد: همس فضائي منخفض،
نقرات خفيفة مع اتصال خطوط الكوكبة، صفير الشهاب، أزيز ذيل
المذنّب وهو يرسم الشعار، ضربة وانفجار أبيض مع الضوء، ثم حفيف خفيف مع ظهور الاسم.
المستوى ‎−19 LUFS‎ بمدى ديناميكي واسع، فالمؤثرات تبقى هادئة ولا تزاحم أي
موسيقى تُضاف لاحقًا.

## تعديل الكلمات أو التوقيت

كل الحركة في دالة واحدة `render(t)` داخل `index.html`:

- الكلمات الثلاث في المصفوفة `WORDS` (النص، الترجمة، وقت الدخول والخروج).
- أحجام الشعار ومواضعه في `layout()`، ومسار المذنّب يتبع مسار الشعار نفسه.
- لمعاينة لحظة معيّنة: `index.html?t=12.5` عبر خادم محلي.

## إعادة التصدير

npx http-server -p 8080 .   # معاينة حيّة: http://localhost:8080
FFMPEG=/path/to/ffmpeg ./build.sh
