# صور المواقع

ضع هنا صور المواقع اللي تظهر لما تضغط على نقطة في الأرض أو المريخ أو القمر.

- اسم كل صورة مكتوب في `places.js` تحت `images` لكل موقع، مثل `earth-muscat-1.jpg`.
- الصيغ المقبولة: JPG أو PNG أو WebP. الأفضل بعرض 1600 بكسل تقريبًا وحجم أقل من 500 كيلوبايت.
- إذا الصورة غير موجودة، يظهر مكانها إطار مكتوب فيه اسم الملف المطلوب.
- لتغيير الاسم أو إضافة تعليق تحت الصورة، عدّل `places.js`.
