# شاشة الدخول (Splash Screen) — مبنيّة على الشعار

شاشة افتتاحية تظهر فور فتح التطبيق/الموقع، تتحرّك فيها أجزاء الشعار نفسها،
ثم تنطلق العلامة يمينًا وتختفي لتظهر الصفحة.

- **الشعار متجّه (SVG)** مُستخرَج من الصورة الأصلية — حادّ عند أي مقاس.
- **بدون أي مكتبة خارجية** — لا Framer Motion ولا خطوط من الإنترنت.
- **صفر طلبات شبكة للشعار**: مرسوم داخل الصفحة (inline SVG)، فلا تظهر الشاشة
  أبدًا بلا شعار ولا يحدث وميض.
- وضع فاتح وداكن، عربية و**RTL** بالكامل، ومتجاوبة من ٣٢٠px فأعلى.
- الاختفاء مرتبط **بجاهزية التطبيق الحقيقية**، لا بمؤقّت وهمي.

```bash
npx http-server -p 8080 -c-1 .
# الموقع مع الشاشة:   http://localhost:8080
# معاينة الحركة وحدها: http://localhost:8080/splash-preview.html
```

(`mark-bar1/2/3` و`mark-arrow` و`mark-j`) حتى يتحرّك كل جزء وحده.

| الملف | الاستخدام |

| `assets/brand/app-icon-maskable.svg` | نسخة أندرويد القابلة للقص (العلامة ضمن ٧٢٪ الآمنة) |

| `assets/brand/icon-512.png` · `icon-192.png` | أيقونات `manifest` |
| `assets/brand/icon-maskable-512.png` | `purpose: maskable` |
| `assets/brand/apple-touch-icon.png` | أيقونة iOS عند «إضافة إلى الشاشة الرئيسية» |
| `assets/logo.svg` · `assets/favicon-32.png` | الشعار العام: بلاطة بزوايا دائرية (الترويسة + التبويب) |

ألوان الهوية مأخوذة من الصورة نفسها:

| الدور | اللون |
|---|---|
| لون العلامة (الحبر) | `#042421` |
| بداية التدرّج | `#45E2C3` |
| منتصف التدرّج | `#88F5E0` |
| نهاية التدرّج | `#55DAFD` |

## شريط الحركة

| الزمن | ما يحدث |
|---|---|
| `0ms` | التدرّج يظهر فورًا (قبل أي JavaScript) + هالة تتنفّس ببطء |
| `60–220ms` | أسطر السرعة تمتدّ من اليسار، متتابعة |
| `120ms` | حرف **J** يستقرّ من أسفل مع تكبير طفيف |
| `180ms` | السهم ينطلق من أسفل اليسار إلى موضعه |
| `480–760ms` | العنوان ثم الفاصل ثم العبارة ثم شريط التقدّم |
| `900ms` ثم كل `2.8s` | لمعة تمرّ فوق العلامة (مقصوصة على شكلها) |
| `1s` ثم كل `2.4s` | نبضة في أسطر السرعة — إحساس حركة مستمرّ بدل دوّارة |
| عند الجاهزية | العلامة تنطلق يمينًا وتتلاشى الشاشة، والمحتوى يدخل متتابعًا |

مع `prefers-reduced-motion` يختفي كل ما سبق ويبقى ظهور بالتلاشي فقط.

## الدمج في موقع HTML

الترتيب داخل `<head>` **مقصود ومهم**: `splash.css` هو ملف التنسيق الوحيد الذي
يحجب الرسم، فتظهر الشاشة فورًا؛ أما تنسيق الموقع فيُحمَّل بشكل غير حاجب حتى لا
يؤخّرها.

```html
<link rel="stylesheet" href="src/splash/splash.css">

<script>
  /* يضع الصنف js + شبكة أمان زمنية تحرّر الموقع لو فشل تحميل splash.js */
  (function () {
    var r = document.documentElement;
    r.classList.add('js');
    setTimeout(function () {
      if (r.classList.contains('app-ready')) return;
      r.classList.remove('splash-lock');
      r.classList.add('app-ready');
      var s = document.querySelector('[data-splash]');
      if (s) s.remove();
    }, 10000);
  })();
</script>

<link rel="stylesheet" href="css/site.css" media="print" onload="this.media='all'">
<noscript><link rel="stylesheet" href="css/site.css"></noscript>
```

ثم في `<body>`: ضع قالب الشاشة (انسخه من `index.html` — ومعه الشعار المرسوم
داخله) كأول عنصر، ولُفّ موقعك بعنصر يحمل `data-app-root`، وأضف
`data-splash-enter` لأي عنصر تريده يدخل بلطف بعد الاختفاء. وأخيرًا:

```html
<script type="module">
  import { createSplash, indexEnterTargets } from './src/splash/splash.js';
  indexEnterTargets();
  createSplash({ appRoot: '[data-app-root]' });
</script>
```

> إن لم تضع القالب في HTML، تُنشئه الوحدة تلقائيًا (والشعار يأتي من `MARK_SVG`)
> — لكن وضعه في HTML أسرع ظهورًا لأنه لا ينتظر تحميل الـ JavaScript.

## الدمج في React / Next.js

انسخ `splash.css` و`SplashScreen.jsx`، ثم في `app/layout.jsx`:

```jsx
import '@/styles/splash.css';
import SplashScreen from '@/components/SplashScreen';

export default function RootLayout({ children }) {
  return (
    <html lang="ar" dir="rtl" className="js">
      <body>
        <SplashScreen />
        <div data-app-root>{children}</div>
      </body>
    </html>
  );
}
```

المكوّن يُرسَم ضمن HTML الأولي (SSR) فيظهر فورًا بلا وميض. أضف نفس السكربت
التمهيدي أعلاه في الـ layout للحصول على شبكة الأمان نفسها.

## تثبيت كتطبيق (PWA)

`manifest.webmanifest` يجعل الموقع قابلًا للتثبيت، فتصير شاشة الدخول هي شاشة
فتح التطبيق فعليًا:

- **أندرويد**: يرسم النظام شاشة بداية من `background_color` + أيقونة الـ manifest،
  ثم تكمل شاشتنا بنفس التدرّج — فيبدو الفتح قطعة واحدة بلا قفزة لونية.
- **iOS**: الأيقونة من `apple-touch-icon`، و`apple-mobile-web-app-capable`
  يفتح الموقع بلا شريط المتصفّح.
- `theme-color` له نسختان (فاتح/داكن) ليطابق أعلى الشاشة في الحالتين.

غيّر الاسم والعبارة في `manifest.webmanifest` و`index.html` معًا.

## الخيارات

| الخيار | الافتراضي | الوصف |
|---|---|---|
| `title` | `قسم الأنشطة الطلابية` | العنوان |
| `tagline` | `نصنع تجربة طلابية استثنائية` | العبارة |
| `mark` | `MARK_SVG` | شِفرة SVG للشعار |
| `markup` | — | قالب كامل بديل للشاشة |
| `minDuration` | `950` | أقل مدة ظهور (تمنع الوميض) |
| `maxDuration` | `7000` | **سقف صارم** — لا تحجب المستخدم أبدًا |
| `exitDuration` | `620` | مدة التلاشي |
| `waitFor` | `[]` | وعود إضافية (جلب بيانات مثلًا) |
| `once` | `'always'` | `'session'` = مرة واحدة لكل جلسة |
| `appRoot` | `[data-app-root]` | يُعطَّل أثناء التحميل (`inert`) |

مثال — انتظار بيانات قبل الإخفاء:

```js
createSplash({ waitFor: [fetch('/api/events').then(r => r.json())] });
```

## تغيير الهوية البصرية

كل الألوان في متغيّرات CSS أعلى `splash.css` — غيّرها وحدها ويتبعها كل شيء
(الخلفية، العلامة، الفاصل، شريط التقدّم):

```css
:root {
  --brand-ink: #042421;        /* لون العلامة */
  --brand-teal: #45e2c3;       /* بداية التدرّج */
  --brand-aqua: #88f5e0;       /* منتصفه */
  --brand-sky: #55dafd;        /* نهايته */
  --splash-mark-size: clamp(8rem, 34vw, 14rem);
}
```

الوضع الداكن يتبع إعداد الجهاز تلقائيًا، ويمكن فرضه يدويًا:

```html
<html data-theme="dark">   <!-- أو "light" لتثبيت الفاتح -->
```

## الأداء وإمكانية الوصول

- الشعار داخل الصفحة: لا طلب شبكة له، ولا حالة «شاشة بلا شعار».
- تُزال الشاشة من DOM بعد الاختفاء — لا تكلفة ولا اعتراض للنقر.
- قفل التمرير أثناء العرض فقط، ثم يُحرَّر.
- `role="status"` و`aria-live` و`progressbar` بنسبة حقيقية.
- الشعار `aria-hidden` (زخرفي)، والنص هو ما يقرأه القارئ الصوتي.
- الموقع يُعطَّل بـ `inert` أثناء التحميل فلا يصله تركيز لوحة المفاتيح.
- `prefers-reduced-motion`: تلاشٍ بسيط بلا انزلاق ولا نبض ولا لمعة.
- بدون JavaScript: لا تظهر الشاشة إطلاقًا ويعمل الموقع طبيعيًا.

### ثلاث شبكات أمان تمنع حجب الموقع

1. `maxDuration` (٧ ثوانٍ) — يُنهي الشاشة حتى لو تعثّر التحميل.
2. السكربت التمهيدي (١٠ ثوانٍ) — يعمل حتى لو فشل تحميل `splash.js`.
3. الصنف `js` — بدون JavaScript لا تُعرض الشاشة أساسًا.

## ما جرى التحقق منه فعليًا

**الشعار**: رُسمت المسارات المتجّهة ثم قورنت بالصورة الأصلية بيكسلًا ببكسل —
تطابق **٩٨٫١٪** (IoU)، أي فرق بحدود حافة واحدة ناعمة، وبقية الفرق من ضغط JPEG.

**الشاشة** — صُوّرت في Chromium داخل إطار بعرض الجوال الحقيقي
(Chromium بلا واجهة يفرض عرض نافذة ٥٠٠px كحد أدنى، فالتصوير المباشر يخدع):

- `390×844`: تسلسل الحركة كاملًا إطارًا بإطار كل `60ms` من `0` إلى `2160ms`،
  ثم انتقال الخروج حتى `660ms`.
- `320×568` و`360×640`: العنوان والعبارة يتّسعان بلا قصّ ولا تمرير أفقي.
- `820×400` (أفقي): قاعدة `max-height: 560px` تعمل — شعار أصغر، وإخفاء العبارة.
- الوضع الفاتح والداكن، تلقائيًا و`data-theme` يدويًا في الاتجاهين.
- الدورة كاملة: الشاشة تُزال من DOM، ويُضاف `app-ready`، ويُرفع `aria-busy`،
  ويُرفع `inert` عن المحتوى، وبلا أي خطأ JavaScript.
- `manifest.webmanifest` وكل ملفات الأيقونات تُخدَم بنجاح.

منطق التوقيت وشبكات الأمان لم يتغيّر عن النسخة السابقة التي اختُبرت سابقًا
(تحميل بطيء، فشل `splash.js`، تعطيل JavaScript).
