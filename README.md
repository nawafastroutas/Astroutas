# ⭐ الافتتاحية (`src/opening/`)

## لماذا الخروج هكذا؟

الشاشة لا تنزاح كستارة. عند الخروج **ينقشع البياض وحده** بينما **ينتقل الشعار
نفسه** — بحركة FLIP تقيس موضعه في الشاشة وموضع شعار الهيدر لحظتَها — إلى
مكانه في الترويسة. النتيجة أن الموقع يبدو وكأنه **تجمّع**، لا وكأن ستارةً
رُفعت عنه. وإن غاب شعار الهيدر رجع الخروج تلقائيًا إلى تلاشٍ بسيط.

## القواعد الخمس

كلٌّ منها يمنع عطلًا بعينه:

1. **مرّة واحدة لكل جلسة تصفّح** — لا مع كل تنقّل بين الصفحات.
2. **تُتجاوَز كليًا** مع «تقليل الحركة» أو إن فُتح الموقع في تبويب خلفي.
3. **شبكة أمان زمنية** تُخفيها مهما حدث، فلا تحجب الموقع أبدًا.
4. **الموقع مرسوم تحتها من البداية** — لا يتأخّر المحتوى ولا يُحجب عن محركات البحث.
5. **القرار يسبق الرسم لا يتبعه** — الشاشة تُرسم ظاهرة، وسكربتٌ متزامن في
   `<head>` يُسقطها قبل أول رسمة عند اللزوم. لو رُسمت مخفيّة ثم كُشفت، لرأى
   الزائر المحتوى أولًا ثم غطّته الشاشة بعده — وهو أسوأ من غيابها.

> السكربت يحقن `<style>` ولا يكتب سمة على `<html>`. السبب: React يقارن سمات
> الجذر عند الهيدريشن، فسمةٌ يكتبها سكربت قبله تُعدّ اختلافًا ويُسجَّل خطأ.
> أما `<style>` مُضاف من خارج الشجرة فلا يقارنه أحد.

## الشعار — مشتقٌّ بالقياس، لا مرسوم ولا متتبَّع

الشعار هنا ليس رسمًا تقريبيًّا، ولا تتبُّعًا لمضلّعات. هو **البناء الهندسيّ
نفسه الذي رُسم به الشعار أصلًا**، مستخرَجًا بالقياس من ملفه:

```
أربع دوائر متساوية، نصف قطرها 71.68
مراكزها أركان مستطيل 167×107
مضروبة بقلم عرضه 12.47
ومقصوصة بذلك المستطيل  ←  فلا يظهر من كل دائرة إلا رُبعها
+ معيّن أوسط 28×48 أضلاعه أربعة أقواس مقعّرة
```

**خطأ ملاءمة الدوائر: نصف بكسل.** ذلك ما يجعلنا نجزم أن هذا هو البناء الأصلي
لا تقريبًا له.

### كيف استُخرج

| # | الخطوة | الأداة |
|---|---|---|
| ١ | فكّ ترميز الصورتين وقراءة بكسلاتهما | Chromium |
| ٢ | مطابقة الملوّنة بالبيضاء (نفس العمل بمقياس ١.٧٨) | — |
| ٣ | تصنيف كل بكسل بإسقاط لونه على الخطّ الواصل بين لونَي الهوية | — |
| ٤ | استخراج محور كل شريط وعرضه | تحويل المسافة (Felzenszwalb) |
| ٥ | ملاءمة دائرة لمحور كل قوس | أقل المربّعات (Kása) |
| ٦ | قياس المعيّن بملاءمة مقيّدة تمرّ برؤوسه | بحث أحاديّ البُعد |
| ٧ | استنتاج ترتيب التشابك من ألوان مناطق التقاطع | — |

الخطوة ٢ مهمّة: النسخة البيضاء أعلى دقّة فتعطي حدودًا أنعم، والملوّنة تعطي
لون كل بكسل — فنأخذ من كلٍّ أفضل ما فيها.

### ما كشفه التحليل

- **الشعار متشابكٌ كالعقدة.** عند التقاطع الأيسر يمرّ الفيروزيّ فوق
  البنفسجيّ، وعند الأيمن العكس. لم نلحظ هذا بالعين، بل بعدّ ألوان بكسلات
  التقاطع: يسارًا ١١٩ فيروزيًّا مقابل ٢٩ بنفسجيًّا، ويمينًا ١٤٠ بنفسجيًّا
  مقابل ٨ فيروزية. ولأن جانبَي الشعار لا يتلامسان، يكفي **ترتيب الرسم**
  لإعادة التشابك — بلا أقنعة.
- **لا امتزاج عند التقاطعات.** ما ظننّاه امتزاجًا كان بكسلات حوافٍّ منعَّمة.
- **الأقواس أرباع دوائر** تنتهي مستويةً عند حدود المستطيل، لأن القصّ هو ما
  ينهيها لا نهاية القوس.
- **الألوان مقيسة**: `#612775` و`#73a2b1` — لا `#7a2d76` و`#8cbfc0` كما
  خُمّنت أوّلًا.

### لماذا يهمّ هذا

| | متتبَّع | مشتقّ بالقياس |
|---|---|---|
| الحجم | ٨٫١ ك.ب | **١٫٢ ك.ب** |
| التكبير | يرث تسنُّن المصدر | **دقيق عند أي مقاس** |
| الحركة | الأقواس مقطوعة عند التقاطعات فتظهر ثُلَم | **أقواس كاملة تنزلق سليمة** |
| التعديل | تحريك نقطة نقطة | **غيّر نصف القطر أو عرض القلم** |

### إعادة التوليد

```bash
node tools/derive-logo.mjs <الصورة الملوّنة> <الصورة البيضاء>
# يكتب assets/club-logo.svg ويطبع معاملات البناء
```

إن وصل ملفٌ رسميٌّ أدقّ (`.svg` أو `.ai` أو `.eps`) فشغّل الأداة عليه —
تُقاس المعاملات من جديد ويُحدَّث الشعار آليًّا.

## الدمج — HTML عادي

```html
<link rel="stylesheet" href="src/opening/club-splash.css">
<script>/* الصق CLUB_SPLASH_BOOT هنا inline — يجب ألّا ينتظر أي ملف */</script>
```

ثم ضع قالب الشاشة (انسخه من `club.html`) كأول عنصر في `<body>`، وأعطِ شعار
الهيدر الصنف `club-header-mark` (هو هدف الطيران)، وأخيرًا:

```html
<script type="module">
  import { createClubSplash } from './src/opening/club-splash.js';
  createClubSplash();
</script>
```

## الدمج — React / Next.js

```jsx
import '@/styles/club-splash.css';
import { ClubSplash } from '@/components/club-splash';
import { ClubSplashBoot } from '@/components/club-splash-boot';
import { ClubMark } from '@/components/club-mark';

export default function RootLayout({ children }) {
  return (
    <html lang="ar" dir="rtl">
      <head><ClubSplashBoot /></head>
      <body>
        <ClubSplash />
        <header><ClubMark className="club-header-mark" /></header>
        {children}
      </body>
    </html>
  );
}
```

> الشعار يستعمل **أصنافًا** (`club-mark-left/right/seed`) لا مُعرّفات `id`.
> المرجع استعمل `#arc` و`#shard`، لكن الشعار يُرسم مرّتين — في الشاشة وفي
> الهيدر — فتتكرّر المُعرّفات وتصير HTML غير صالحة. الأصناف تحلّ هذا.

## المعاينة

`?splash=1` يفرض العرض متجاوزًا علامة الجلسة — للمعاينة دون مسح تخزين المتصفّح.

```bash
npx http-server -p 8080 -c-1 .
# http://localhost:8080/club.html?splash=1
```

## ما جرى التحقق منه فعليًا

اختُبر في Chromium عبر Playwright:

| الحالة | النتيجة |
|---|---|
| الخروج على سطح المكتب | `leaving="fly"` — الطيران نجح، والهيدر عاد ظاهرًا، وقفل التمرير رُفع |
| مطابقة الشعار للأصل | تراكب بصري على الصورة الأصلية — لا انحراف في الحدود |
| الزيارة الثانية في الجلسة | `display:none` والموقع ظاهر فورًا |
| `prefers-reduced-motion` | لا شاشة إطلاقًا — بـ CSS وحده |
| **بدون JavaScript** | ظاهرة عند ١ث، **مُزاحة عند ٦.٦ث** بسياج CSS، والموقع يعمل |
| الجوال ٣٩٠×٨٤٤ | لا تمرير أفقي |
| أخطاء JavaScript | **لا شيء** |

# «مِداد» (`src/entrance/`) وشاشة قسم الأنشطة (`src/splash/`)

وحدة **«مِداد»** موثّقة بالكامل في تاريخ المستودع وصفحتها `midad.html`:
قطرة حبر، زخرفة ثمانية تُرسم بالقلم، الاسم يُكتب من اليمين لليسار، وبيت شعر
متبدّل — بثلاث سمات (`ink` / `paper` / `night`) وزرّ تخطٍّ.

## ملحق: شاشة تحميل قسم الأنشطة الطلابية (`src/splash/`)

وحدةٌ سابقة مستقلّة تمامًا عن الدخولية، بهوية زرقاء/برتقالية وصفحة عرض في
`index.html`. تشترك مع الدخولية في المبدأ نفسه (الاختفاء مرتبط بالجاهزية
الحقيقية + شبكات أمان زمنية)، وتختلف في الفكرة البصرية والخيارات.

| الملف | الدور |
|---|---|
| `src/splash/splash.css` | التنسيق + متغيّرات الهوية |
| `src/splash/splash.js` | المتحكّم |
| `src/splash/react/SplashScreen.jsx` | نسخة React / Next.js |
| `index.html` | صفحة العرض |

```js
import { createSplash, indexEnterTargets } from './src/splash/splash.js';
indexEnterTargets();
createSplash({ logoSrc: 'assets/logo.svg', appRoot: '[data-app-root]' });
```
