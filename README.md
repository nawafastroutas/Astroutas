# نادي الثقافة والأدب — موقع النادي

موقع نادٍ طلابي في **كلية التربية بالرستاق**، جامعة التقنية والعلوم التطبيقية.
عربي بالكامل، اتجاه RTL، ومواعيده كلّها بتوقيت سلطنة عُمان.

> **بلا أي تبعية خارجية.** لا إطار عمل، ولا مكتبة، ولا خطوط من الإنترنت:
> خادم Node المدمج، وSQLite المدمجة في Node، ومولّد رمز QR مكتوب في المشروع.
> (مستودعا npm وPyPI محجوبان بسياسة الشبكة في بيئة التطوير هذه، وقد جاء هذا
> القيد في مصلحة المشروع: تثبيت بلا خطوات، وسطح هجوم أصغر، وبلا تحديثات تبعيات.)

---

## التشغيل

```bash
node --version          # يلزم 22.5 فأحدث (SQLite مدمجة)

npm run seed            # بيانات تجريبية للعرض (اختياري)
npm start               # http://localhost:3000
npm test                # ٣١ فحصًا
```

حساب الإدارة في البيانات التجريبية: **٩١٠٠٠٠٠١**
(الدخول برقم الجوال وحده، بلا كلمة سر).

لمنح صلاحية الإدارة لعضو مسجَّل:

```bash
npm run admin -- 91234567
```

## الشعار

الشعار في `public/assets/logo.svg` **إعادة رسم** للعلامة (قوسان بنفسجيّان
متقاطعان يحفّهما قوسان فيروزيّان)، لأنّ ملفّ الشعار الرسمي لم يصل كملفّ.
**ضع الملفّ الرسمي مكانه بالاسم نفسه** ولا حاجة لتعديل أي سطر — هو مصدر
الشعار في الترويسة وشاشة التحميل وأيقونة التبويب.

ألوان الهوية مستخرجة من الشعار، وكلّها متغيّرات في أعلى `public/css/site.css`:

```css
--plum-600: #6e2a72;    /* بنفسجي الشعار */
--teal-500: #7fb3b0;    /* فيروزي الشعار */
```

## البنية

```
server.js                نقطة التشغيل
src/
  config.js              كل الإعدادات (بيئة التشغيل تغلبها)
  app.js                 الموجِّه: ملفّات ثابتة، جلسة، فحص منشأ، صلاحيات
  db/schema.sql          الجداول والقيود والمشغّل وعروض النقاط
  lib/                   qr, ics, csv, storage, session, ratelimit, validate,
                         datetime (توقيت عُمان)، arabic (العدد والمعدود)، html
  models/                قواعد العمل: الحجز، المسح، التقييم، النقاط
  routes/                public · auth · member · admin
  views/                 layout · pages · admin  (HTML من الخادم، بلا بناء)
  splash/                شاشة التحميل (وحدة مستقلّة قابلة لإعادة الاستخدام)
public/                  css · js · assets
tests/                   qr · rules · validate
data/                    قاعدة البيانات والصور (خارج git)
```

لا خطوة بناء ولا حزم: ما تكتبه هو ما يعمل.

## القواعد كما نُفِّذت

### العضوية

| القاعدة | التنفيذ |
|---|---|
| الدخول برقم الجوال وحده | `POST /login` — بلا كلمة سر، مع حدّ ١٥ محاولة/٥ دقائق لكل IP |
| الاسم الثلاثي | ثلاث كلمات فأكثر، كل كلمة حرفان فأكثر، حروف فقط، ٧٠ حرفًا حدًّا أقصى |
| الجوال | ثمانية أرقام عُمانية تبدأ بـ ٧ أو ٩، أو دولي بمفتاح الدولة. الأرقام العربية (٠١٢٣) تُقبل وتُحوَّل |
| الرقم الجامعي | أرقام فقط، ٥–١٢ خانة |
| الإيميل | لا بدّ أن ينتهي بـ `@utas.edu.om` |
| التفرّد | قيود `UNIQUE` في القاعدة، وكل تكرار له **رسالته المحدَّدة** («هذا الرقم الجامعي مسجّل بعضوية أخرى») لا رسالة قاعدة بيانات |
| الجلسة | كعكة `HttpOnly` مبصومة بـ HMAC-SHA256، صالحة أسبوعًا، بلا حالة على الخادم |

### الحجز والحضور والنقاط

- **تذكرة واحدة لكل عضو لكل فعالية** — يحرسها `UNIQUE (member_id, event_id)`
  في القاعدة، لا شرط في الشيفرة. الشيفرة تترجم القيد إلى رسالة عربية فقط.
- الحجز يُرفض إذا كانت الفعالية غير منشورة، أو منتهية، أو اكتملت سعتها
  (الفحص داخل معاملة `BEGIN IMMEDIATE`).
- **نافذة المسح**: تفتح قبل البداية بساعتين، وتغلق بعد النهاية باثنتي عشرة ساعة.
- المسح يمنح: نقاط الفعالية + شارتها + بطاقة حضور، **مرّة واحدة** مهما تكرّر.
  الإعادة تُعلَم «ممسوحة من قبل» ولا تمنح شيئًا — يحرسها `UNIQUE (ticket_id)`.
- **التقييم**: زرّ في الموقع يمنح ١٠ نقاط مرّة واحدة ثمّ يحوّل إلى الاستبيان.
  **رابط الاستبيان الخارجي لا يوجد في HTML أي صفحة** — يصل فقط في ردّ
  `POST /events/:id/evaluate`، فلا سبيل لفتح الاستبيان بلا احتساب.
- **مجموع النقاط يُحسب ولا يُخزَّن**: العرض `member_points` يجمع الحضور
  والتقييمات مباشرةً، والفعاليات التجريبية (`is_test`) خارج الحساب.
  لا عمود نقاط في جدول الأعضاء أصلًا، فلا يمكن أن يختلف المجموع عن مصدره.

### الإدارة

- الدخول مقيَّد بمن يملك `is_admin`.
- **يُمنع حذف فعالية سُجّل فيها حضور** — يرفضه مشغّل `BEFORE DELETE` في
  القاعدة نفسها (وليس الشيفرة)، وتُقترح «الإلغاء» بدلًا منه.
- تصدير CSV بترميز UTF-8 **مع BOM** لتُقرأ العربية في Excel، والخلايا التي
  تبدأ بـ `=` أو `+` تُبطَّل حتى لا تُنفَّذ كصيغ حسابية.
- المسح بالكاميرا عبر `BarcodeDetector`، ومعه إدخال يدوي يعمل في أي متصفّح.

### الأمان

| الإجراء | التفصيل |
|---|---|
| حدود المعدّل | الدخول ١٥/٥د · الحجز ٢٠/١٠د · المراسلة ٤/١٠د · المسح ١٢٠/د · الرفع ٦٠/١٠د |
| فحص المنشأ | كل طلب يغيّر الحالة: `Sec-Fetch-Site` أولًا (ترويسة لا تُزوَّر)، ثم `Origin`، ثم `Referer` |
| سياسة أمان المحتوى | `script-src 'self'` مع nonce لكل طلب — لا سكربت مضمَّن بلا توقيع |
| الصور | تخزين كائنات بمفاتيح عشوائية (١٢٨ بتّة) لا تُخمَّن، وحدّ حجم، والنوع يُعرف من بصمة الملفّ لا من ترويسة العميل |
| الخصوصية | أسماء المسجَّلين لا تُكشف قبل انتهاء الفعالية |
| الترويسات | `nosniff` · `frame-ancestors 'none'` · `Referrer-Policy` |

### الإتاحة

رابط «تخطَّ إلى المحتوى»، وبنية عناوين متدرّجة، و`aria-live` في المسح
والتقييم، وبدائل نصّية لكل صورة ورمز QR، وتباين ألوان كافٍ، ووضع داكن
تلقائي، واحترام `prefers-reduced-motion` في كل حركة (بما فيها شاشة التحميل).
الموقع يعمل **بلا JavaScript**: كل النماذج تُرسَل عاديًّا، والتقييم يحوّل
بردّ 303، ولا تظهر شاشة التحميل أصلًا.

## النشر

```bash
SESSION_SECRET=<سرّ عشوائي طويل>   # وإلا وُلِّد محلّيًّا في data/
BASE_URL=https://club.utas.edu.om   # لروابط رموز QR وملفّات التقويم
PORT=3000
NODE_ENV=production
```

ضع الموقع خلف وكيل عكسي يوفّر HTTPS (تُرفع الكعكة إلى `Secure` تلقائيًّا
عند وصول `X-Forwarded-Proto: https`). البيانات كلّها في `data/` — انسخها
احتياطيًّا. لنقل الصور إلى S3/R2 يكفي استبدال ثلاث دوالّ في
`src/lib/storage.js` (`putObject` / `getObject` / `deleteObject`).

## ما جرى التحقّق منه فعليًّا

- **٣١ فحصًا آليًّا** (`npm test`): قواعد التسجيل والحجز والمسح والتقييم
  والنقاط وحذف الفعاليات والجلسات وحدود المعدّل وفحص المنشأ والتخزين
  والتقويم والتصدير.
- **مولّد QR**: قورنت سعة الإصدارات ١–١٥ بجداول المواصفة المنشورة
  (٦٠ قيمة)، وطابق تصحيح Reed–Solomon متّجه الاختبار في ISO/IEC 18004،
  وطابقت ٣٢ قيمة لمعلومات النسق و٩ لمعلومات الإصدار، ويُفكّ ترميز كل رمز
  بمسار مستقلّ فيعود النصّ كما هو (عربي ولاتيني وروابط، بمستويات التصحيح الأربعة).
- **تدفّقات حقيقية عبر HTTP**: الدخول، التسجيل برسائل التكرار المحدَّدة،
  الحجز ورفضه (منتهية/مسودّة/مكتملة)، المسح ثم إعادته، التقييم مرّتين،
  حذف فعالية فيها حضور (٤٠٩)، تصدير CSV، وفحص المنشأ (٤٠٣)، وحدّ المراسلة (٤٢٩).
- **المتصفّح**: صفحات الموقع ولوحة الإدارة على ١٢٨٠×٩٥٠ و٣٩٠×٨٤٤ بلا أخطاء
  JavaScript، مع ظهور شاشة التحميل واختفائها وتسليم الصفحة.

**ما لم يُختبر على جهاز حقيقي**: المسح بكاميرا الجوال (يحتاج متصفّحًا يدعم
`BarcodeDetector` — كروم على أندرويد) وقراءة رمز التذكرة بماسح فعلي؛
وحفظ التذكرة صورة يعتمد على رسم النصّ العربي في `canvas` بخطوط الجهاز.
