# دخولية نادي الثقافة والأدب — كلية التربية بالرستاق

شاشة افتتاحية (Entrance / Splash) تظهر فور فتح الموقع، ثم تُطوى كصفحة كتابٍ
عربيّ لتكشف الصفحة الرئيسية.

> هذا المستودع يحوي **وحدتين مستقلّتين**:
> 1. `src/entrance/` — **دخولية نادي الثقافة والأدب** (العمل الأحدث، موثّق أدناه).
> 2. `src/splash/` — شاشة تحميل قسم الأنشطة الطلابية (عمل سابق، انظر آخر الملف).

---

## الفكرة: «مِداد»

الدخولية ليست شعارًا يدور في انتظار التحميل. إنها **مشهدٌ قصير** مبنيّ على
معنى النادي نفسه — الكتابة:

| # | اللحظة | ماذا يحدث |
|---|---|---|
| ١ | `0.14s` | **قطرةُ حبرٍ** تسقط من أعلى الشاشة، تستطيل أثناء السقوط، ثم تنبطح عند الاصطدام. |
| ٢ | `0.70s` | **لطخةُ حبرٍ** تتفتّح مكان الاصطدام بحوافٍّ غير منتظمة. |
| ٣ | `0.62s` | **زخرفةٌ ثمانية** (دائرة + مربّعان متقاطعان) تُرسم بالقلم ضربةً بعد ضربة، ثم تدور نصفاها في اتجاهين متعاكسين. |
| ٤ | `0.84s` | **الشعار يرسم نفسه**: أقواسه الأربعة تُخطّ واحدًا تلو الآخر، ثم تتفتّح البذرة الوسطى. |
| ٥ | `1.35s` | **اسم النادي يُكتب** من اليمين إلى اليسار، و**سنُّ قلمٍ** متوهّجة تركب حدّ الحبر تمامًا. |
| ٦ | `2.25s` | **بيتُ شعرٍ** يظهر بين علامتَي ﴿ ﴾ مع اسم قائله — ويتبدّل كل ٣.٢ث. |
| — | طوال المشهد | حروف **«أبجد هوّز»** تتهادى صاعدةً في الخلفية كغبار مكتبةٍ في شعاع ضوء. |
| ٧ | الخروج | الشاشة **تُطوى حول كعبها الأيمن** (كصفحة في كتابٍ عربي) بينما يدخل المحتوى تحتها. |

**لماذا هذا أفضل من صورة متحرّكة؟** لأن الشعار مبنيٌّ من أقواس، فتحويله إلى
`SVG` يجعله يُخطّ أمام المستخدم بدل أن يظهر جاهزًا — وهي حركةٌ لا يمكن لصورة
`PNG` أو `GIF` أن تؤدّيها، وتزن كيلوبايتات معدودة.

---

## ⚠️ عن الشعار — اقرأ هذا

وصلني الشعار **كصورة** لا كملفٍّ متجهيّ، فأعدتُ بناءه `SVG` يدويًا:
أربعة أقواس متداخلة (بنفسجيّان خارجًا، فيروزيّان داخلًا) وبذرةٌ وسطى، بألوان
الهوية `#7A2D76` و`#8CBFC0`.

**هو تقريبٌ للأصل، لا نسخةٌ طبق الأصل.** إن كان لديكم الملف الرسمي
(`.svg` أو `.ai` أو `.eps`) فاستبداله يحتاج تعديلًا واحدًا:

- بدّل محتوى `assets/club-logo.svg` (يُستعمل في الترويسة وأيقونة الموقع).
- وبدّل ثابت `LOGO` في `src/entrance/entrance.js` بمسارات الشعار الرسمي.
  حافظ على `class="ent-logo-arc"` و`pathLength="100"` على كل مسار كي تبقى
  حركة الخطّ تعمل، واستعمل `stroke="var(--logo-plum)"` / `var(--logo-teal)`
  كي يتبدّل الشعار تلقائيًا مع السمة الفاتحة والداكنة.

## التشغيل

```bash
npx http-server -p 8080 -c-1 .
# ثم افتح http://localhost:8080/club.html
```

جرّب السمات: `?theme=ink` (الافتراضية) · `?theme=paper` · `?theme=night`

## السمات الثلاث

| السمة | المزاج | متى تستعملها |
|---|---|---|
| `ink` | بنفسجيٌّ عميق، الفيروزي يتوهّج عليه | الافتراضية — الأقوى أثرًا |
| `paper` | ورقٌ فاتح بمسطرة كرّاسٍ باهتة | الأقرب لهوية الشعار على الأبيض |
| `night` | ليلٌ بنفسجي والحروف نجوم | الأمسيات الشعرية والمناسبات |

تُبدَّل بخيار واحد: `createEntrance({ theme: 'paper' })`.

## الدمج في موقع HTML

ترتيب `<head>` **مقصود**: `entrance.css` هو ملف التنسيق الوحيد الحاجب للرسم،
فتظهر الدخولية فورًا؛ أمّا تنسيق الموقع فيُحمَّل بشكل غير حاجب حتى لا يؤخّرها.

```html
<link rel="stylesheet" href="src/entrance/entrance.css">

<script>
  /* الصنف js + شبكة أمان زمنية تحرّر الموقع لو فشل تحميل entrance.js */
  (function () {
    var r = document.documentElement;
    r.classList.add('js');
    setTimeout(function () {
      if (r.classList.contains('app-ready')) return;
      r.classList.remove('entrance-lock');
      r.classList.add('app-ready');
      var s = document.querySelector('[data-entrance]');
      if (s) s.remove();
      if (document.body) document.body.removeAttribute('aria-busy');
    }, 12000);
  })();
</script>

<link rel="stylesheet" href="css/site.css" media="print" onload="this.media='all'">
<noscript><link rel="stylesheet" href="css/site.css"></noscript>
```

ثم في `<body>`: ضع قالب الدخولية (انسخه من `club.html`) **كأول عنصر**، ولُفّ
موقعك بعنصرٍ يحمل `data-app-root`، وأضف `data-entrance-enter` لكل عنصرٍ تريده
يدخل بلطفٍ بعد الطيّ. وأخيرًا:

```html
<script type="module">
  import { createEntrance, indexEnterTargets } from './src/entrance/entrance.js';
  indexEnterTargets();
  createEntrance({ appRoot: '[data-app-root]' });
</script>
```

> إن لم تضع القالب في HTML تُنشئه الوحدة تلقائيًا — لكن وضعه في HTML **أسرع
> ظهورًا** لأنه لا ينتظر تحميل الـ JavaScript.

## الدمج في React / Next.js

```jsx
import '@/styles/entrance.css';
import EntranceScreen from '@/components/EntranceScreen';

export default function RootLayout({ children }) {
  return (
    <html lang="ar" dir="rtl" className="js">
      <body>
        <EntranceScreen theme="ink" once="session" />
        <div data-app-root>{children}</div>
      </body>
    </html>
  );
}
```

المكوّن يُرسَم ضمن HTML الأوّلي (SSR) فيظهر فورًا بلا وميض. أضف السكربت
التمهيدي نفسه في الـ layout للحصول على شبكة الأمان ذاتها.

## الخيارات

| الخيار | الافتراضي | الوصف |
|---|---|---|
| `title` | `نادي الثقافة والأدب` | الاسم الذي يُكتب بالقلم |
| `tagline` | `كلية التربية بالرستاق` | السطر تحت شريط التقدّم |
| `theme` | `'ink'` | `ink` · `paper` · `night` |
| `verses` | ٦ أبيات موثّقة النسبة | `[{ text, by }]` |
| `verseInterval` | `3200` | مدّة بقاء البيت (ms) |
| `letters` | `16` | عدد الحروف العائمة (`0` = تعطيل) |
| `minDuration` | `2800` | أقل مدة ظهور — تترك المشهد يكتمل |
| `maxDuration` | `9000` | **سقف صارم** — لا تحجب المستخدم أبدًا |
| `exitDuration` | `620` | مدّة طيّ الصفحة |
| `skippable` | `true` | زرّ «تخطّي المقدّمة» + مفتاح `Esc` |
| `skipAfter` | `1100` | متى يظهر زرّ التخطّي (ms) |
| `waitFor` | `[]` | وعودٌ إضافية (جلب بيانات مثلًا) |
| `once` | `'always'` | `'session'` = مرّة واحدة لكل جلسة |
| `appRoot` | `[data-app-root]` | يُعطَّل بـ `inert` أثناء العرض |

**توصية للإنتاج:** استعمل `once: 'session'`. الزائر يرى المشهد كاملًا في أول
دخول، ثم تُفتح الصفحات التالية فورًا بلا انتظار.

```js
createEntrance({
  once: 'session',
  waitFor: [fetch('/api/events').then((r) => r.json())],
});
```

عند انتهاء الدخولية يُطلَق حدث:

```js
document.addEventListener('club:entrance-done', (e) => {
  console.log(e.detail.reason); // 'ready' | 'timeout' | 'skip' | 'manual'
});
```

## الأداء وإمكانية الوصول

- **صفر اعتماديات**: لا مكتبات، لا خطوط من الإنترنت، لا صور نقطية.
  الحركات عبر CSS و`requestAnimationFrame` فقط.
- الخطوط من **خطوط النظام العربية** — لا طلب شبكة ولا وميض خطوط.
- تُزال الدخولية من DOM بعد الطيّ: لا تكلفة ولا اعتراض للنقر.
- قفل التمرير أثناء العرض فقط، ثم يُحرَّر.
- `role="progressbar"` بنسبةٍ حقيقية، و`role="status"` على سطر الحالة وحده
  (لا على الشاشة كلها) كي لا يُكرّر قارئ الشاشة كل بيتٍ يتبدّل.
- الأبيات والزخارف `aria-hidden` — زينةٌ لا محتوى.
- الموقع يُعطَّل بـ `inert` أثناء العرض فلا يصله تركيز لوحة المفاتيح.
- `prefers-reduced-motion`: بلا سقوط ولا دوران ولا حروف طائرة — تلاشٍ فقط.
- زرّ **تخطّي** + مفتاح `Esc` احترامًا لوقت الزائر.

### أربع شبكات أمان تمنع حجب الموقع

1. `maxDuration` (٩ث) — يُنهي المشهد حتى لو تعثّر التحميل.
2. السكربت التمهيدي (١٢ث) — يعمل حتى لو فشل تحميل `entrance.js` كلّيًا.
3. الصنف `js` — بدون JavaScript لا تُعرض الدخولية أصلًا.
4. `Promise.allSettled` — فشل خطٍّ أو صورة لا يُبقي الشاشة عالقة.

## ما جرى التحقق منه فعليًا

اختُبر في Chromium عبر Playwright. النتائج المسجّلة:

| الحالة | النتيجة |
|---|---|
| سطح المكتب ١٤٤٠×٩٠٠ — السمات الثلاث | تُفتح الصفحة بعد ~٣.٧ث، بلا أخطاء |
| الجوال ٣٩٠×٨٤٤ و٣٢٠×٥٦٨ | التخطيط سليم، لا تمرير أفقي |
| الجوال أفقيًا ٧٤٠×٤٠٠ | يُخفى البيت تلقائيًا، لا ازدحام |
| `prefers-reduced-motion` | بلا حركة، ويكتمل التسلسل (~٣.٤ث) |
| تنسيق الموقع بطيء (٣ث) | الدخولية **مرسومة بعد ٣٣ms** |
| تعثّر التحميل تمامًا | السقف الصارم فتح الموقع عند ~٩.٩ث |
| فشل تحميل `entrance.js` | السكربت التمهيدي حرّر الموقع عند ١٣ث |
| JavaScript معطّل | لا دخولية إطلاقًا، والموقع ظاهرٌ ومنسّق |
| زرّ التخطّي / مفتاح `Esc` | يفتحان الموقع فورًا (~٢.٢ث) |
| بعد الخروج | النقر والتمرير وتركيز لوحة المفاتيح تعمل |
| أخطاء JavaScript | **لا شيء** في كل الحالات أعلاه |

# ملحق: شاشة تحميل قسم الأنشطة الطلابية (`src/splash/`)

وحدةٌ سابقة مستقلّة تمامًا عن الدخولية، بهوية زرقاء/برتقالية وصفحة عرض في
`index.html`. تشترك مع الدخولية في المبدأ نفسه (الاختفاء مرتبط بالجاهزية
الحقيقية + شبكات أمان زمنية)، وتختلف في الفكرة البصرية والخيارات.

| الملف | الدور |
|---|---|
| `src/splash/splash.css` | التنسيق + متغيّرات الهوية |
| `src/splash/splash.js` | المتحكّم |
| `src/splash/react/SplashScreen.jsx` | نسخة React / Next.js |
| `index.html` | صفحة العرض |

```js
import { createSplash, indexEnterTargets } from './src/splash/splash.js';
indexEnterTargets();
createSplash({ logoSrc: 'assets/logo.svg', appRoot: '[data-app-root]' });
```
