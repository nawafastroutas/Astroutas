# لعبة أسئلة — تطبيق آيفون (SwiftUI)

تطبيق آيفون **أصلي** بمهمة واحدة فقط: جولة من ١٠ أسئلة عربية، ١٥ ثانية لكل
سؤال، ونتيجة في النهاية. بدون أي مكتبة خارجية، وبدون إنترنت، وبدون حسابات.

<img src="AstroQuiz/Assets.xcassets/AppIcon.appiconset/AppIcon.png" width="110" alt="أيقونة التطبيق">

---

## ⚠️ اقرأ هذا أولًا

كُتب التطبيق في بيئة **لينكس بلا ماك ولا Xcode**، لذلك:

- **لم أتمكّن من بنائه أو تشغيله أو تجربته.** الكود مراجَع يدويًا سطرًا سطرًا،
  لكنه لم يمرّ على مترجم Swift ولا على محاكي الآيفون.
- أول خطوة عندك: افتح المشروع في Xcode واضغط **⌘R**. لو ظهر أي خطأ ترجمة،
  أرسله لي وأصلحه فورًا.
- ملف المشروع `AstroQuiz.xcodeproj` مكتوب بصيغة Xcode القياسية
  (`objectVersion = 56`، متوافق مع Xcode 14 فما فوق).

---

## التشغيل

```
1. افتح ios/AstroQuiz.xcodeproj في Xcode  (يتطلب Xcode 15+ وiOS 17+)
2. اختر أي محاكي آيفون من الأعلى
3. اضغط ⌘R
```

**للتشغيل على جهاز آيفون حقيقي:** اختر الهدف `AstroQuiz` ← تبويب
**Signing & Capabilities** ← اختر فريقك في **Team**، وغيّر
`PRODUCT_BUNDLE_IDENTIFIER` إلى معرّف خاص بك (مثل `com.اسمك.astroquiz`).

## كيف تُلعب

| | |
|---|---|
| الجولة | ١٠ أسئلة تُسحب عشوائيًا من بنك فيه **٤٠ سؤالًا** |
| الوقت | ١٥ ثانية لكل سؤال، شريط يفرغ من اليمين ويحمرّ في آخر ٥ ثوانٍ |
| النقاط | ١٠٠ لكل إجابة صحيحة **+** حتى ٦٠ مكافأة سرعة **+** حتى ٦٠ مكافأة تتابع |
| الخيارات | ٤ خيارات، ترتيبها يُخلط في كل جولة فلا يُحفظ مكان الجواب |
| بعد الجواب | يظهر الصحيح بالأخضر والخطأ بالأحمر، ثم ينتقل تلقائيًا — أو المس الشاشة للتعجيل |
| النهاية | النتيجة، عدد الصحيح، أطول تتابع، وأفضل نتيجة محفوظة على الجهاز |

كل شيء عربي و **RTL** بالكامل مهما كانت لغة الجهاز، مع اهتزاز خفيف عند كل جواب.

## إضافة أسئلة

افتح `QuestionBank.swift` وأضف في نهاية المصفوفة. **الجواب الصحيح يُكتب في
`correct` دائمًا** ويُخلط مكانه تلقائيًا:

```swift
Question(.science, "ما أسرع حيوان بري؟",
         correct: "الفهد",
         wrong: ["الأسد", "الحصان", "الغزال"]),
```

التصنيفات المتاحة في أعلى `Question.swift`: `general`, `science`, `geography`,
`math`, `culture`, `tech`, `sports`.

## تغيير إعدادات اللعبة

في أعلى `QuizEngine.swift`:

```swift
static let roundSize = 10          // عدد أسئلة الجولة
static let questionTime: Double = 15   // ثواني كل سؤال
static let revealDelay: Double = 1.15  // مدة إظهار الجواب قبل الانتقال
```

والألوان كلها في أعلى `Theme.swift` — نفس ألوان هوية شاشة التحميل في المشروع
(`#06162c` و`#1e6fd9` و`#f5851f`).
